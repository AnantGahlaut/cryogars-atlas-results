Valid cells

Valid stored — cells with a finite value after recorded processing, divided by all cells in the stored archive rectangle at the stated grid spacing. Values may be measured, derived or interpolated. Missing or invalid count metadata is shown as unknown.

Valid shown — samples with finite layer and terrain values on the current rendering grid, divided by all sampled grid positions. Its count and spacing update with the shown mesh detail. Zero is valid, including a mask's zero state. This describes grid samples, not visible screen pixels, viewport clipping or triangle counts.

Changing rendering detail samples the existing terrain-aligned array; it does not average new blocks. Finer or coarser sampling can raise or lower the percentage. Temporary comparisons have no stored archive dataset: their shown count follows the selected A, B or difference result, with differences requiring finite values from both inputs.

Valid display in Details counts finite cells in the exported display grid before terrain mapping or rendering detail. Export block averaging can make this percentage higher than stored validity without adding measurements; edge cropping and product-specific reductions can also change it.

These counts describe data availability, not measurement quality or the fraction passing a coherence cutoff.
